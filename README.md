# 6th INFOTEX RSVP — Versi Percuma

Template landing page RSVP percuma untuk acara, seminar, program pelajar dan majlis rasmi.

## Ciri-ciri

- Landing page responsive untuk desktop dan mobile
- RSVP form dengan Google Sheets
- Google Maps dan Google Calendar
- E-Card jemputan
- Switcher Bahasa Melayu / English
- Countdown acara
- Animasi ringan dan aksesibiliti reduced-motion

## Cara guna

1. Salin atau fork repository ini.
2. Tukar maklumat acara dalam `index.html` dan `enhancements.js`.
3. Masukkan URL Google Apps Script Web App dalam `script.js`.
4. Terbitkan melalui GitHub Pages.

Versi percuma ini disediakan untuk kegunaan sendiri dan satu acara. Logo, kandungan dan warna boleh disesuaikan oleh pengguna.
